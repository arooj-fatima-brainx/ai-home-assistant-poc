# T-005: Simulator: availability, last will and saved state
- Milestone: M1
- Depends on: T-004
- Use cases: UC-03, UC-04
## Goal
Devices show as Unavailable when the simulator stops and come back with the same state when it starts again.
## Definition of Done (copied from use cases)
- [ ] UC-03-E2: Given the simulator is stopped (`docker compose stop simulator`), when the developer looks at HA, then all 11 devices show "Unavailable" within 5 seconds.
- [ ] UC-03-E3: Given the simulator is started again, when it reconnects, then the devices are available again with the same states they had before it stopped (state file).
- [ ] UC-04-E4: Given the bedroom AC is at 22 °C, when the simulator is restarted, then the AC is still at 22 °C (state file).
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `main.py`: set an MQTT last will per client so the broker publishes `offline` on every device's availability topic when the simulator disconnects. aiomqtt allows one will per client, so use one shared availability topic for all devices (for example `sim/availability`) in discovery (`availability` list with both the shared topic and the per-device topic, `availability_mode: all`), or publish `offline` on clean shutdown (SIGTERM) and rely on the will for crashes. Pick one, write the reason in the walkthrough.
- `simulator/sim/state_store.py`: save all device states to a JSON file (for example `simulator/state/state.json`, git-ignored) after each change; load it at start. Add `simulator/state/` to `.gitignore`. Faults are not saved (T-007).
- Keepalive short enough that HA shows Unavailable within 5 seconds of `docker compose stop simulator`.
- Tests: state store save/load round trip; missing or corrupt file falls back to defaults with a warning.
## Manual test steps
1. In HA, turn on the bedroom light; set bedroom AC to 22 °C.
2. E2: `docker compose stop simulator`. Within 5 seconds all 11 devices show "Unavailable".
3. E3: `docker compose start simulator`. Devices are available again; the bedroom light is still on.
4. E4: `docker compose restart simulator`. Bedroom AC is still at 22 °C.
5. `cat simulator/state/state.json` shows the saved states; `git status` does not list it.
6. `cd simulator && pytest`.
