# T-020: Tool-calling spike script
- Milestone: M1
- Depends on: T-001
- Use cases: UC-17
## Goal
A throwaway script sends one sentence and one tool definition to gpt-4o-mini and prints the chosen tool call and token counts, without touching any device.
## Definition of Done (copied from use cases)
- [ ] AC-17.1 Given the text "turn on the kitchen light", when the script runs, then it prints tool `control_light` with arguments `{"entity_id": "light.kitchen_light", "action": "turn_on"}`.
- [ ] AC-17.2 Given any run, when it finishes, then it prints input and output token counts and the time taken.
- [ ] AC-17.3 Given any run, when the developer checks HA, then no device changed.
- [ ] UC-17-E1: Given `OPENAI_API_KEY` is empty, when the script runs, then it stops with "OPENAI_API_KEY is not set" (no stack trace).
- [ ] UC-17-E2: Given the text "hello", when the script runs, then it prints "No tool call" and the model's text reply.
- [ ] UC-17-E3: Given the text "turn on the garage light" (not in the list), when the script runs, then it prints what the model did (a text reply or a call with one of the two listed lights). This is recorded as a finding for the M2 prompt, not a failure.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `backend/scripts/spike_tool_call.py`: reads `OPENAI_API_KEY` and `OPENAI_MODEL` from settings; one tool `control_light` with `strict: true`, `entity_id` enum `["light.kitchen_light", "light.bedroom_light"]`, `action` enum `["turn_on", "turn_off"]`; prints tool name, arguments, `usage.prompt_tokens`, `usage.completion_tokens`, elapsed seconds. No HA calls.
- Missing key: print "OPENAI_API_KEY is not set" and exit 1 (no stack trace). No tool call: print "No tool call" and the text reply.
- Pin `openai`. The backend container mounts `./backend` at `/app`, so the script runs as `python scripts/spike_tool_call.py`.
- Write the E3 result (what the model did) in the walkthrough as a finding for the M2 prompt.
- Tests: one unit test for the missing-key path; real calls are manual only.
## Manual test steps
1. `docker compose exec backend python scripts/spike_tool_call.py "turn on the kitchen light"`. Expect `control_light` with `{"entity_id": "light.kitchen_light", "action": "turn_on"}`, token counts and time.
2. Check HA: no device changed.
3. E2: run with `"hello"`. Expect "No tool call" and a text reply.
4. E3: run with `"turn on the garage light"`. Note what the model did.
5. E1: empty `OPENAI_API_KEY` in `.env`, `docker compose up -d backend`, run again. Expect "OPENAI_API_KEY is not set". Restore the key.
6. `cd backend && pytest`.
