# T-049: Push-to-talk button
- Milestone: M3
- Depends on: T-048
- Use cases: UC-42
## Goal
Hold the microphone button to record and release to send; the transcript shows as the user's message and the rest works like text.
## Definition of Done (copied from use cases)
- [ ] AC-42.1 (T17) Given the living room main light is off, when the member holds the button and says "Turn on the living room main light", then the transcript shows and the light turns on.
- [ ] AC-42.2 (T17) Given the T8 start states, when the member speaks T8, then the results match the text version.
- [ ] AC-42.3 Given the member is holding the button, when they look at it, then it shows a recording state (colour and timer) until released.
- [ ] UC-42-E1: Given the microphone permission is denied, when the member presses the button, then "Microphone access is blocked. Allow it in your browser settings." shows.
- [ ] UC-42-E2: Given the member releases in under 0.5 seconds or says nothing, when the audio is processed, then "I didn't catch that. Please try again." shows and the LLM is not called.
- [ ] UC-42-E3: Given the member holds for more than 30 seconds, when 30 seconds pass, then recording stops and is sent automatically.
- [ ] UC-42-E5: Given a phone-sized screen, when the member presses and holds with a finger, then recording works and the page does not scroll or select text.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
Frontend rules for every M3 ticket (CLAUDE.md): reusable components; colors, type, spacing and sizes only from the design tokens in `frontend/src/styles/tokens.css`; light mode only; responsive at 390, 768 and 1280 px; touch targets at least 44 px; back buttons return to where the user came from. The frontend has no test runner (ask before adding one): checks are `npm run lint`, `npm run build` and the manual steps.
- `frontend/src/assistant/voice/PushToTalkButton.tsx` with `useRecorder.ts` (`MediaRecorder`, pointer events so mouse and touch both work, `touch-action: none`, `user-select: none`). Recording state: color and timer. Auto stop at 30 s. Under 0.5 s -> "I didn't catch that. Please try again." without upload.
- Permission denied -> "Microphone access is blocked. Allow it in your browser settings."
- Upload to `/voice`; show the transcript as the user message, then the reply like text.
## Manual test steps
1. Hold the mic button, say "Turn on the living room main light", release -> transcript shows, the light turns on (T17).
2. Speak T8 from its start states -> same results as the text version.
3. While holding: the button changes color and a timer runs.
4. E1: block the microphone in site settings, press -> the blocked message.
5. E2: tap quickly -> "I didn't catch that. Please try again."
6. E3: hold for 31 s -> recording stops at 30 s and is sent.
7. E5: Chrome device mode (iPhone, touch), press and hold -> records; the page does not scroll or select text.
8. `cd frontend && npm run lint && npm run build`.
