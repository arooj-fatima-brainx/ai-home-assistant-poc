# T-022: Home snapshot and generated tool schemas
- Milestone: M2
- Depends on: T-021
- Use cases: UC-26
## Goal
Build the LLM's view of a home from the live HA cache: a JSON snapshot block and typed, strict tool schemas whose enums list only this home's devices and options.
## Definition of Done (copied from use cases)
- [ ] UC-26-E2: Given a device that was removed from `devices.yaml` a minute ago, when the member asks for it, then the reply says it does not exist (the snapshot is fresh).
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `backend/app/agent/snapshot.py`: `build_snapshot(home, ha_snapshot, recent_entity_ids)` -> dict with home name, timezone, local time, rooms with aliases, and per device `entity_id`, `name`, aliases, `type`, limits, state, availability, plus `recent_devices` (filled in T-025). Rendered as a labelled JSON block (ARCHITECTURE.md 8.2; device names are data, not instructions).
- `backend/app/agent/tools.py`: `build_tool_schemas(ha_snapshot)` -> `control_light`, `control_ac`, `control_fan`, `get_device_state`, `get_sensor_reading`, `list_devices`, each `strict: true`, all fields required, nullable where optional (ARCHITECTURE.md 8.3). A tool is left out when the home has no device of that type.
- `backend/scripts/show_agent_context.py <home_id>`: prints the snapshot and tool schemas for a home. A learning and debugging aid.
- Both are rebuilt on every request; nothing hard-coded.
- Tests: `tests/test_agent_snapshot.py`, `tests/test_agent_tools.py` using `tests/fixtures/ha_test_home.json` (enums match the 11 devices; bedroom AC modes only in the snapshot limits; kitchen light marked not dimmable; tool missing when no device of that type).
## Manual test steps
1. `docker compose exec backend python scripts/show_agent_context.py $HOME_A`. Check the snapshot lists 3 rooms, "lounge" on Living room, 11 devices with limits and states.
2. Check `control_ac` lists both AC entity IDs; `control_light` lists 4 lights; every tool has `"strict": true`.
3. Toggle the kitchen light in HA, run again; the snapshot shows the new state.
4. E2: remove the living room lamp from `devices.yaml`, wait 10 s, run again; the lamp is gone from the snapshot and the `control_light` enum. Put it back.
5. `cd backend && pytest`.
