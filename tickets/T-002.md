# T-002: Home Assistant setup checklist in the README
- Milestone: M1
- Depends on: T-001
- Use cases: UC-02
## Goal
Write the manual first-time HA setup as a numbered README checklist and follow it once on the running stack.
## Definition of Done (copied from use cases)
- [ ] AC-02.1 Given the README setup checklist, when the developer follows it step by step, then HA ends with an admin user, the MQTT integration and a long-lived token, with no step missing from the checklist.
- [ ] AC-02.2 Given the MQTT integration is added with the HA credentials, when the developer opens Settings > Devices & services > MQTT, then it shows as connected (no error badge).
- [ ] AC-02.3 Given the alias "lounge" is added, when the developer opens Settings > Areas > Living room, then "lounge" is listed as an alias.
- [ ] AC-02.4 Given HA is restarted (`docker compose restart homeassistant`), when the developer logs in again, then the admin user, MQTT integration, areas and aliases are still there.
- [ ] UC-02-E1: Given the developer types a wrong MQTT password in the integration form, when they submit, then HA shows a connection error and the integration is not added.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- Docs only, no code. `README.md` section "Home Assistant first-time setup":
  1. Onboarding: create the admin user, location Lahore, timezone Asia/Karachi.
  2. Settings > Devices & services > Add integration > MQTT: broker `mosquitto`, port `1883`, `HA_MQTT_USERNAME` / `HA_MQTT_PASSWORD` from `.env`.
  3. Areas: Living room, Bedroom and Kitchen are created by discovery later (T-003); add the alias "lounge" to Living room after that step.
  4. Profile > Security > Long-lived access tokens > Create token "ai-home-assistant". Copy it; it is needed in T-014.
- Keep only `ha-config/configuration.yaml` tracked; check `.gitignore` covers the rest of `ha-config/`.
- UC-02-E2 (deleted token) is tested in T-014 and T-015, where the app reports it.
- Tests: none (manual setup by design).
## Manual test steps
1. On a fresh HA (or the one from T-001), follow the README checklist step by step. Tick each step; note any missing step.
2. E1: add the MQTT integration with a wrong password first. Expect a connection error; nothing is added. Then use the right password.
3. Settings > Devices & services > MQTT. Expect no error badge.
4. After T-003 creates the areas, add "lounge" to Living room; check Settings > Areas > Living room lists it. (Before T-003, create the area by hand to test the alias, then delete it.)
5. `docker compose restart homeassistant`, log in again. Expect the admin user, MQTT and the alias still there.
6. `git status`. Expect no new files under `ha-config/` except `configuration.yaml`.
