# T-034: Access control sweep for every M2 route
- Milestone: M2
- Depends on: T-033
- Use cases: UC-32, UC-18
## Goal
Prove that no route or tool lets a non-member, a logged-out user or another home reach `$HOME_A`.
## Definition of Done (copied from use cases)
- [ ] AC-32.1 (T19) Given B is not a member, when B tries to start a conversation, send a message, read members or read conversations of `$HOME_A`, then every response is `404` and no device changes.
- [ ] UC-32-E1: Given no cookie, when any M2 route is called, then the response is `401` "Not logged in".
- [ ] UC-32-E2: Given B has their own home connected to the same HA, when B asks "turn on the kitchen light" in B's home, then it works only through B's home (each home has its own connection).
- [ ] UC-18-E1: Given two members A and B of the same home, when each lists conversations, then each sees only their own conversations.
- [ ] UC-18-E3: Given a conversation ID from another home or another user, when the member reads it, then the response is `404` "Conversation not found".
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- No new feature. Add one parametrized test `tests/test_access_control.py` that walks every `/api/homes/{home_id}/...` route in the app (from `app.routes`) and checks: no cookie -> `401`; non-member -> `404`; nothing changed in HA (mock not called). New routes are then covered automatically.
- Check each home has its own `HAClient` (UC-32-E2): two homes on the same HA URL get two clients.
- Fix any route that fails.
## Manual test steps
1. Sara is not a member of `$HOME_A`. With `-b b.txt` call: `POST $BASE/homes/$HOME_A/conversations`, `POST .../conversations/$CONV/messages`, `GET .../members`, `GET .../conversations`. Each `404`; HA unchanged.
2. E1: the same calls with no cookie -> `401` "Not logged in".
3. E2: as Sara create her own home, connect it to the same HA (T-014), start a conversation in it and send "turn on the kitchen light" -> works through Sara's home.
4. UC-18-E1: add Sara to `$HOME_A` (T-032). Each user lists conversations in `$HOME_A` -> each sees only their own.
5. UC-18-E3: as Sara, read Ali's `$CONV` messages -> `404` "Conversation not found".
6. `cd backend && pytest -k access_control`, then `pytest`.
