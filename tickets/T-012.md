# T-012: Who am I and log out
- Milestone: M1
- Depends on: T-011
- Use cases: UC-10
## Goal
`GET /api/auth/me` returns the user and `POST /api/auth/logout` clears the cookie.
## Definition of Done (copied from use cases)
- [ ] AC-10.1 Given a logged-in user, when they call `GET /api/auth/me`, then it returns `200` with `id`, `name`, `email` and `homes` (an empty list before UC-11).
- [ ] AC-10.2 Given a logged-in user, when they call `POST /api/auth/logout`, then the response is `204` and the cookie is cleared (`Max-Age=0`).
- [ ] AC-10.3 Given the user logged out, when they call `GET /api/auth/me`, then the response is `401` "Not logged in".
- [ ] UC-10-E1 (T22): Given no cookie, when `GET /api/auth/me` is called, then the response is `401` "Not logged in".
- [ ] UC-10-E2: Given no cookie, when `POST /api/auth/logout` is called, then the response is still `204` (logging out twice is not an error).
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `backend/app/auth/router.py`: `POST /api/auth/logout` -> `204`, calls `clear_login_cookie` (`Max-Age=0`). No `current_user` needed, so it works without a cookie.
- `GET /api/auth/me` response model: `id`, `name`, `email`, `homes` (list of `{id, name}`; empty until T-013).
- UC-10-E3 (two homes) is in T-013.
- Tests: `tests/test_auth_me_logout.py`.
## Manual test steps
1. Log in as Ali (T-011 step 1). `curl -b a.txt $BASE/auth/me`. Expect `id`, `name`, `email`, `homes: []`.
2. `curl -i -b a.txt -c a.txt -X POST $BASE/auth/logout`. Expect `204` and `Max-Age=0` in `Set-Cookie`.
3. `curl -i -b a.txt $BASE/auth/me`. Expect `401` "Not logged in".
4. E1: `curl -i $BASE/auth/me` (no cookie). Expect `401`.
5. E2: repeat step 2. Expect `204`.
6. `cd backend && pytest`.
