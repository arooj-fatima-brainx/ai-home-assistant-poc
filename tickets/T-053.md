# T-053: Device command endpoint (Should)
- Milestone: M3
- Depends on: T-052
- Use cases: UC-46
## Goal
`POST /api/homes/{id}/devices/{entity_id}/command` changes one setting through the same validation, HA call and confirmation as the assistant's tools.
## Definition of Done (copied from use cases)
- [ ] UC-46-E1: Given the bedroom AC is at 28 °C, when the member looks at the + button, then it is disabled; and if `{"temperature": 35}` is sent to the endpoint with `curl`, the response is `422` "Bedroom AC allows 18 to 28 °C".
- [ ] UC-46-E4: Given a non-member, when they call the command endpoint for `$HOME_A`, then the response is `404` "Home not found".
- [ ] UC-46-E5: Given a field that does not fit the device (`{"brightness": 50}` for the kitchen light), when it is sent, then the response is `422` "This light can't be dimmed".
- [ ] AC-46.4 Given the member changed the AC on the dashboard, when they then say "make it a bit warmer" in the chat, then the assistant starts from the new temperature (it reads HA, not old chat values).
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `backend/app/devices/router.py`: `POST .../devices/{entity_id}/command` with one of `brightness`, `temperature`, `mode`, `fan_speed`, `speed`. Map to the same tool-layer function as `control_light` / `control_ac` / `control_fan` (T-023), so there is one validation path.
- `invalid` from the tool layer -> `422` with the message (for example "Bedroom AC allows 18 to 28 °C", "This light can't be dimmed"); other statuses -> `200` with the `DeviceResult`.
- Tests: valid change, out of range `422`, wrong field for device `422`, non-member `404`.

1. `curl -s -b a.txt -X POST $BASE/homes/$HOME_A/devices/climate.bedroom_ac/command -H 'Content-Type: application/json' -d '{"temperature": 23}'` -> `ok`; HA shows 23.
2. E1: same with `{"temperature": 35}` -> `422` "Bedroom AC allows 18 to 28 °C".
3. E5: `light.kitchen_light` with `{"brightness": 50}` -> `422` "This light can't be dimmed".
4. E4: with `-b b.txt` (non-member) -> `404` "Home not found".
5. AC-46.4: set the AC with step 1, then in chat say "make it a bit warmer" -> starts from 23.
6. `cd backend && pytest`.
