# T-059: Manage rooms through Home Assistant: backend (Could)
- Milestone: M4
- Depends on: T-058

## Goal
Backend routes create, rename and delete rooms, move devices and edit aliases through HA's WebSocket API, storing nothing in SQLite.
## Definition of Done (copied from use cases)
- [ ] AC-51.1 Given the member creates the room "Study", when they open HA > Settings > Areas, then "Study" exists.
- [ ] UC-51-E1: Given a room name that already exists, when it is created, then "A room with this name already exists" shows.
- [ ] All tests pass. Reviewer approved. Verifier passed.
