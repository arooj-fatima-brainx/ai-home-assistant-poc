# T-046: Live dashboard: device cards by room
- Milestone: M3
- Depends on: T-045
- Use cases: UC-40
## Goal
The dashboard shows every device by room and updates within about a second when anything changes, reconnecting by itself.
## Definition of Done (copied from use cases)
- [ ] AC-40.1 Given the home is connected, when the dashboard loads, then it shows Living room, Bedroom and Kitchen with their 11 devices, and AC cards show set point and mode, fan cards show speed, sensor cards show temperature and humidity.
- [ ] AC-40.2 Given the dashboard is open, when the kitchen light is switched in the HA UI, then the kitchen card updates within 1 second without a page reload.
- [ ] AC-40.4 Given a device is added in `devices.yaml`, when HA adds it, then its card appears within 10 seconds without a reload.
- [ ] UC-40-E3: Given the backend restarts, when the WebSocket drops, then the dashboard shows "Reconnecting..." and reconnects on its own, then reloads the states.
- [ ] UC-40-E4: Given the room temperature drifts (UC-05), when the sensor changes, then the sensor card updates without a reload.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
Frontend rules for every M3 ticket (CLAUDE.md): reusable components; colors, type, spacing and sizes only from the design tokens in `frontend/src/styles/tokens.css`; light mode only; responsive at 390, 768 and 1280 px; touch targets at least 44 px; back buttons return to where the user came from. The frontend has no test runner (ask before adding one): checks are `npm run lint`, `npm run build` and the manual steps.
- `frontend/src/assistant/dashboard/Dashboard.tsx`, `RoomSection.tsx`, `DeviceCard.tsx` with variants for light (state, brightness), AC (set point, mode), fan (speed), sensor (temperature, humidity), offline style.
- `frontend/src/realtime/useHomeSocket.ts`: one WebSocket per open home (`/ws/homes/:id`), reconnect with backoff, "Reconnecting..." banner, on reconnect reload `GET .../devices`. `device_state` updates one card; `devices_changed` reloads the list.
- Load the initial list from `GET /api/homes/{home_id}/devices` (T-016).
## Manual test steps
1. Open the assistant page next to HA. The dashboard shows Living room, Bedroom, Kitchen and 11 cards; AC shows set point and mode, fan speed, sensors temperature and humidity.
2. Toggle the kitchen light in HA -> the card updates within 1 s, no reload.
3. Add the Bedroom lamp to `devices.yaml` -> its card appears within 10 s. Remove it.
4. E3: `docker compose restart backend` -> "Reconnecting...", then it reconnects and states reload.
5. E4: turn the bedroom AC on -> the bedroom sensor card changes every drift step (T-006).
6. `cd frontend && npm run lint && npm run build`.
