# T-006: Simulator: room temperature drift
- Milestone: M1
- Depends on: T-005
- Use cases: UC-05
## Goal
Each room sensor moves 1 °C every 30 s toward its room's AC set point when the AC is on, and back toward 32 °C when it is off.
## Definition of Done (copied from use cases)
- [ ] AC-05.1 Given the bedroom sensor reads above 22 °C, when the bedroom AC is turned on at 22 °C (cool), then the bedroom sensor temperature goes down by at least 1 °C within 1 minute, and keeps going down until it reaches 22 °C.
- [ ] AC-05.2 Given the bedroom AC is turned off, when time passes, then the bedroom sensor temperature rises towards 32 °C and stops at 32 °C.
- [ ] AC-05.3 Given the bedroom AC is cooling, when the developer looks at the living room sensor, then it does not change because of the bedroom AC (each sensor follows only its own room's AC).
- [ ] UC-05-E1: Given the sensor already reads exactly the set point, when time passes, then it stays there (no jumping up and down).
- [ ] UC-05-E2: Given the bedroom AC shows its current temperature in HA, when the bedroom sensor changes, then the AC's current temperature in HA shows the same value.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `simulator/sim/drift.py`: pure function `next_temp(current, ac_on, target, ambient, step)` that moves by `step` and never passes the target (clamped). A loop in `main.py` calls it every `drift_interval` seconds per room sensor and publishes the sensor state when it changes.
- `devices.yaml`: top-level `drift: {step: 1, interval_seconds: 30, ambient: 32}`; each sensor uses the AC in the same room.
- The AC discovery uses the room sensor topic for `current_temperature` (ARCHITECTURE.md 5.3 example), so E2 needs no extra code; check it works.
- Tests: `next_temp` cases (down to target, up to ambient, exactly at target stays, step bigger than gap clamps).
## Manual test steps
1. In HA, note the bedroom sensor temperature (32 °C at start). Turn the bedroom AC on, cool, 22 °C.
2. `source .env && docker compose exec mosquitto mosquitto_sub -u "$MQTT_USERNAME" -P "$MQTT_PASSWORD" -t sim/bedroom_sensor/state -v`. Expect 1 °C drops every 30 s until 22, then no more changes.
3. Open the bedroom AC in HA. Its current temperature matches the sensor.
4. Check the living room sensor did not change.
5. Turn the bedroom AC off. Expect the sensor to rise 1 °C every 30 s and stop at 32.
6. Tip: set `interval_seconds: 5` in `devices.yaml` to test faster (needs a simulator restart until T-008), then set it back.
7. `cd simulator && pytest`.
