# T-033: Delete a home
- Milestone: M2
- Depends on: T-032
- Use cases: UC-31
## Goal
A member can delete a home; all its members, conversations and logs go with it, its HA connection closes, and HA itself is not touched.
## Definition of Done (copied from use cases)
- [ ] AC-31.1 Given a home with members and conversations, when a member deletes it, then the response is `204` and the home is gone from every member's `GET /api/homes`.
- [ ] AC-31.2 Given the home was deleted, when the developer checks SQLite, then its `home_members`, `conversations`, `messages`, `tool_logs` and `request_metrics` rows are gone.
- [ ] AC-31.3 Given the home was deleted, when the developer checks HA, then the devices are unchanged (deleting a home in our app never touches HA).
- [ ] UC-31-E1: Given a non-member, when they try to delete the home, then the response is `404` "Home not found" and nothing is deleted.
- [ ] UC-31-E2: Given the home was deleted, when a member calls any route for it, then the response is `404` "Home not found".
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `homes/router.py`: `DELETE /api/homes/{home_id}` -> `204` with `require_member`. Delete in one transaction; rely on `ON DELETE CASCADE` from T-009 (check `PRAGMA foreign_keys=ON` is set on every connection).
- Close and drop the home's `HAClient` in `ha/manager.py`.
- Database impact: deletes rows only; no schema change.
- Tests: cascade removes `home_members`, `conversations`, `messages`, `tool_logs`, `request_metrics`; non-member `404` deletes nothing; deleted home `404` afterwards.
## Manual test steps
1. Create a test home (T-013), connect it (T-014), add Sara (T-032), send one message (T-024). Note its id as `$TEST_HOME`.
2. E1: as a user who is not a member (sign up a third user, or remove Sara first), `curl -i -b b.txt -X DELETE $BASE/homes/$TEST_HOME` -> `404`; the home still exists.
3. As Ali: `curl -i -b a.txt -X DELETE $BASE/homes/$TEST_HOME` -> `204`. `GET $BASE/homes` as Ali and Sara: gone.
4. `sqlite3 data/app.db "select count(*) from home_members where home_id=$TEST_HOME; select count(*) from conversations where home_id=$TEST_HOME;"` -> 0 and 0. Check `messages`, `tool_logs`, `request_metrics` for its conversation IDs too.
5. Check HA: devices unchanged.
6. E2: `curl -i -b a.txt $BASE/homes/$TEST_HOME/devices` -> `404` "Home not found".
7. `cd backend && pytest`.
