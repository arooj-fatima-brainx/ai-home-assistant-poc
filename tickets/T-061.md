## Technical notes
- Only if time is left. Needs a Linux host with host networking (mDNS, IPv6) and HA's Matter Server.
- No app code change expected: HA exposes the light as `light.*` in a room, so it shows up in the snapshot and tools.
- If it can't run on macOS Docker, write what was tried and why in the Matter section of `docs/report.md`.
## Manual test steps
1. Start the matter.js example light, add it in HA through Matter, put it in Living room.
2. In chat: "turn on the Matter light" -> it turns on.
3. If step 1 is not possible: check the report's Matter section explains why.
