# T-038: Frontend foundation: tokens, API client, routing, auth guard
- Milestone: M3
- Depends on: T-037
- Use cases: UC-36
## Goal
Set up the React app's base: design tokens, a shared API client for `/api`, routes, and a guard that sends logged-out visitors to the login page.
## Definition of Done (copied from use cases)
- [ ] AC-36.1 Given a visitor who is not logged in, when they open any app page, then they are sent to the login page.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
Frontend rules for every M3 ticket (CLAUDE.md): reusable components; colors, type, spacing and sizes only from the design tokens in `frontend/src/styles/tokens.css`; light mode only; responsive at 390, 768 and 1280 px; touch targets at least 44 px; back buttons return to where the user came from. The frontend has no test runner (ask before adding one): checks are `npm run lint`, `npm run build` and the manual steps.
- `frontend/src/styles/tokens.css` (colors, font sizes, spacing, radii, breakpoints as CSS custom properties) imported once in `main.tsx`; `index.css` keeps only resets.
- `frontend/src/api/client.ts`: one `apiFetch(path, options)` with `credentials: 'include'`, JSON handling, and typed errors (`ApiError` with status and `detail`; network failure -> "Can't reach the server. Check your connection."). All later API calls go through it.
- `frontend/src/auth/AuthContext.tsx`: loads `GET /api/auth/me` on start; exposes `user`, `refresh`, `logout`.
- Routing with `react-router` (pin exact version): `/login`, `/signup`, `/homes`, `/homes/new`, `/homes/:homeId`, `/homes/:homeId/settings`. `RequireAuth` wrapper redirects to `/login` and remembers the target.
- Base components: `Button` (with loading state), `TextField` (label, error text), `Page` layout, `Spinner`.
- Placeholder pages are fine for routes built later.
## Manual test steps
1. `docker compose up -d --build frontend`. Open http://localhost:5173/ in a private window -> login page (placeholder is fine).
2. Open http://localhost:5173/homes/1 -> sent to the login page.
3. Log in with curl is not shared with the browser, so also check: after T-039, logging in sends you to the page you first asked for.
4. Search the code: no hex colors or px sizes outside `tokens.css` (`grep -rnE "#[0-9a-fA-F]{3,6}|[0-9]+px" frontend/src --include=*.tsx`).
5. `cd frontend && npm run lint && npm run build`.
