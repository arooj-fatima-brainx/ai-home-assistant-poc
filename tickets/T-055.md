## Manual test steps
1. On a phone on BrainX Wi-Fi, open the HTTPS address -> login page, valid certificate.
2. Log in, hold push-to-talk, say T1 -> light on, reply spoken.
3. From mobile data without VPN -> can't connect.
4. Open the `http://` address -> redirected to HTTPS.
5. Desktop DevTools > Application > Cookies -> the login cookie has `Secure`, `HttpOnly`, `SameSite=Lax`.
6. `git log -p | grep -iE "sk-|eyJ"` -> nothing; secrets only in the server `.env`.
