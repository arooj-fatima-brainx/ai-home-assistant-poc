# T-054: Full device controls on the dashboard (Should)
- Milestone: M3
- Depends on: T-053
- Use cases: UC-46
## Goal
Cards get a brightness slider, AC +/- and mode/fan pickers, and fan speed buttons that show only what each device supports.
## Definition of Done (copied from use cases)
- [ ] AC-46.1 Given the living room main light is on, when the member drags its brightness slider to 40% and lets go, then one request is sent and HA shows 40%.
- [ ] AC-46.2 Given the bedroom AC is on at 22 °C, when the member presses + once, then HA shows 23 °C; the card's controls show only this AC's modes (cool, auto) and its range (18 to 28 °C).
- [ ] AC-46.3 Given the bedroom ceiling fan, when the member presses speed 3, then HA shows 60%.
- [ ] AC-46.5 Given the kitchen light (on/off only) and the kitchen exhaust fan (on/off only), when their cards show, then they have only the on/off button.
- [ ] UC-46-E2: Given the member presses + three times quickly, when the requests finish, then the AC ends at the last value pressed (25 °C from 22 °C) and the card shows HA's confirmed value.
- [ ] UC-46-E3: Given the device has `ignore_commands`, when the member changes a setting, then the card goes back to the real state and shows "Device didn't respond".
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
Frontend rules for every M3 ticket (CLAUDE.md): reusable components; colors, type, spacing and sizes only from the design tokens in `frontend/src/styles/tokens.css`; light mode only; responsive at 390, 768 and 1280 px; touch targets at least 44 px; back buttons return to where the user came from. The frontend has no test runner (ask before adding one): checks are `npm run lint`, `npm run build` and the manual steps.
- `DeviceCard` controls: `BrightnessSlider` (send on release only), `TempStepper` (+/- disabled at limits; quick presses debounced so only the last value is sent), `ModePicker` and `FanModePicker` from the device's own lists, `FanSpeedButtons` (1..speeds). On/off-only devices show only the power button.
- After each change show HA's confirmed value; `timeout` -> real state and "Device didn't respond".
- One API helper `sendCommand(homeId, entityId, body)` in `api/devices.ts`.
## Manual test steps
1. Living room main light on: drag brightness to 40% and let go -> one request in Network; HA 40%.
2. Bedroom AC on at 22: press + -> 23 in HA; mode picker shows only cool and auto; + disabled at 28.
3. Bedroom fan: press speed 3 -> HA 60%.
4. Kitchen light and exhaust fan cards: only the on/off button.
5. E2: from 22, press + three times quickly -> ends at 25 in HA; card shows 25.
6. E3: `ignore_commands` on the living room main light, move the slider -> card returns to the real value with "Device didn't respond". Set `normal`.
7. Check at 390 px.
8. `cd frontend && npm run lint && npm run build`.
