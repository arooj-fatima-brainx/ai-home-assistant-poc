# T-035: A new device works with no app change
- Milestone: M2
- Depends on: T-034
- Use cases: UC-34
## Goal
A device added to `devices.yaml` can be controlled by text within seconds, and removing it makes the assistant say it does not exist. No code change.
## Definition of Done (copied from use cases)
- [ ] AC-34.1 (T18) Given the lamp entry was saved 10 seconds ago, when the member says "Turn on the bedroom lamp", then it turns on in HA, with no restart and no code change.
- [ ] AC-34.2 Given the lamp exists, when the member says "Turn on the light in the bedroom", then the assistant now asks which one (bedroom light or bedroom lamp).
- [ ] UC-34-E1: Given the lamp is removed again, when the member asks for it, then the reply says it does not exist.
- [ ] All tests pass. Reviewer approved. Verifier passed.

## Manual test steps
Setup for every M2 manual test (from `docs/use-cases.md` M2 conventions): log in as Ali (`a.txt`), `export HOME_A=<id>`, start a conversation and `export CONV=<id>`, then define:
```bash
say() { curl -s -b a.txt -X POST $BASE/homes/$HOME_A/conversations/$CONV/messages \
  -H 'Content-Type: application/json' -d "{\"text\": \"$1\"}" | python3 -m json.tool; }
new() { export CONV=$(curl -s -b a.txt -X POST $BASE/homes/$HOME_A/conversations | python3 -c 'import sys,json; print(json.load(sys.stdin)["id"])'); echo $CONV; }
```
Reset devices with the on/off endpoint (T-018) or the HA UI before each scenario. Check the meaning of the reply and the state in HA, not the exact words.
1. Add the Bedroom lamp to `simulator/devices.yaml` (T-008 step 1). Wait 10 s. `new`; `say "Turn on the bedroom lamp"` -> on in HA (T18).
2. `new`; `say "Turn on the light in the bedroom"` -> asks bedroom light or bedroom lamp.
3. E1: remove the lamp, wait 10 s, `new`; `say "Turn on the bedroom lamp"` -> says it does not exist.
4. `cd backend && pytest`.
