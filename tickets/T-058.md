# T-058: Code, security and dependency review
- Milestone: M4
- Depends on: T-057
- Use cases: UC-50
## Goal
Review all AI-generated code and dependencies; leave no high or critical audit findings, no secrets in Git, exact versions, and green tests.
## Definition of Done (copied from use cases)
- [ ] AC-50.1 Given the final code, when `pip-audit` and `npm audit` run, then there are no high or critical findings left (or each one is explained in the report).
- [ ] AC-50.2 Given the Git history, when it is searched for secrets (for example with `gitleaks`), then no key, token or password is found.
- [ ] AC-50.3 Given `requirements*.txt` and `package-lock.json`, when they are checked, then every dependency version is pinned exactly.
- [ ] AC-50.4 Given the tests, when `pytest` and `npm run lint && npm run build` run, then they all pass.
- [ ] UC-50-E1: Given an audit finding has no fix available, when it is reviewed, then the risk and reason are written in the report.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- Run `pip-audit -r requirements.txt` (backend and simulator), `npm audit` (frontend), `gitleaks detect`. Fix or explain each finding in `docs/report.md` (UC-50-E1).
- Check every line in `requirements*.txt` uses `==` and `package.json` has no `^`/`~` (or the lock file pins them).
- Run the CLAUDE.md Whole-Change Check over the full diff against `main` (DRY, tokens, responsiveness, membership checks, folder placement, logging rules).
- Team lead signs off (record the date in the report).
## Manual test steps
1. `cd backend && pip-audit -r requirements.txt`; `cd simulator && pip-audit -r requirements.txt`; `cd frontend && npm audit`. No high or critical left, or each explained in the report.
2. `gitleaks detect` in the repo root -> no leaks.
3. `grep -vE "^\s*(#|$)" backend/requirements*.txt simulator/requirements*.txt | grep -v "=="` -> nothing.
4. `cd backend && pytest`; `cd simulator && pytest`; `cd frontend && npm run lint && npm run build` -> all pass.
