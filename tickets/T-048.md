# T-048: Voice endpoint with faster-whisper
- Milestone: M3
- Depends on: T-047
- Use cases: UC-42
## Goal
`POST .../conversations/{id}/voice` takes an audio upload, transcribes it locally and runs it through the same agent as text.
## Definition of Done (copied from use cases)
- [ ] AC-42.4 Given `tests/audio/t1.wav` and `t8.wav`, when `run_eval.py --only T17` runs, then T17 passes through the voice endpoint.
- [ ] UC-42-E2: Given the member releases in under 0.5 seconds or says nothing, when the audio is processed, then "I didn't catch that. Please try again." shows and the LLM is not called.
- [ ] UC-42-E4: Given a file that is not audio is uploaded to `/voice`, when the backend checks it, then the response is `415` "Unsupported audio format".
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
- `backend/app/speech/stt.py`: load `faster-whisper` once at startup (`WHISPER_MODEL`, CPU, int8, models in `./models`), transcribe in a worker thread.
- `backend/app/voice/router.py`: `POST /api/homes/{home_id}/conversations/{id}/voice` (multipart `audio`). Accept webm/ogg/wav (check content type and magic bytes; else `415` "Unsupported audio format"); max 30 s; decode with `ffmpeg`/PyAV. Empty or under 0.5 s transcript -> reply "I didn't catch that. Please try again." without calling the LLM. Otherwise call the same agent loop with `input_mode="voice"`; return `{turn_no, transcript, reply, results}` (audio added in T-050).
- `backend/tests/audio/t1.wav`, `t8.wav` (record or generate with Piper once); `run_eval.py --only T17` sends them through `/voice`.
- Pin `faster-whisper`; document model download in README. Mount `./models`.
- Tests: endpoint with STT mocked (non-audio `415`, empty transcript skips LLM, non-member `404`).
