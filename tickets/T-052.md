# T-052: Responsive layout on phone, tablet and desktop
- Milestone: M3
- Depends on: T-051
- Use cases: UC-45
## Goal
Every page works at 390, 768 and 1280 px: chat and dashboard side by side on desktop, tabs and a conversation drawer on phones.
## Definition of Done (copied from use cases)
- [ ] AC-45.1 Given a desktop screen (1280 px or wider), when the assistant page opens, then chat and dashboard are side by side.
- [ ] AC-45.2 Given a phone screen (390 px), when the assistant page opens, then chat and dashboard are on separate tabs, the conversation list is a drawer, and nothing scrolls sideways.
- [ ] AC-45.3 Given any page at 390 px, 768 px and 1280 px, when it is checked, then all text is readable and every button can be tapped (at least 44 px high).
- [ ] UC-45-E1: Given the phone is turned to landscape, when the assistant page shows, then the layout still works and push-to-talk is reachable.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
Frontend rules for every M3 ticket (CLAUDE.md): reusable components; colors, type, spacing and sizes only from the design tokens in `frontend/src/styles/tokens.css`; light mode only; responsive at 390, 768 and 1280 px; touch targets at least 44 px; back buttons return to where the user came from. The frontend has no test runner (ask before adding one): checks are `npm run lint`, `npm run build` and the manual steps.
- `AssistantPage.tsx`: CSS grid with breakpoints from tokens; at 1280+ chat and dashboard side by side; below the tablet breakpoint tabs "Chat" / "Devices"; `ConversationList` becomes a drawer (shared `Drawer` component).
- Push-to-talk stays visible on both tabs and in landscape.
- Sweep every page for horizontal scroll and buttons under 44 px.
## Manual test steps
1. Chrome device mode at 1280 px: assistant page shows chat and dashboard side by side.
2. iPhone 12 Pro (390 px): tabs for chat and devices; conversation list opens as a drawer; no sideways scroll on any page (login, sign-up, switcher, settings, assistant).
3. iPad (768 px) and 390 px: all text readable; every button at least 44 px high (check with the inspector).
4. E1: rotate the phone view to landscape -> layout works; push-to-talk reachable.
5. Safari on macOS once.
6. `cd frontend && npm run lint && npm run build`.
