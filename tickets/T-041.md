# T-041: Home settings: members and delete home
- Milestone: M3
- Depends on: T-040
- Use cases: UC-38
## Goal
On the settings page a member can add and remove members and delete the home, with a confirmation dialog.
## Definition of Done (copied from use cases)
- [ ] AC-38.3 Given the members section, when the member adds an existing account's email, then it appears in the list; when they click "Remove" and confirm, it disappears.
- [ ] AC-38.4 Given the member clicks "Delete home", when they confirm in the dialog, then the home is deleted and they go to the switcher (or "Create your first home").
- [ ] UC-38-E3: Given an unknown email is added as member, when it is submitted, then "No account with this email" shows under the field.
- [ ] UC-38-E4: Given the member clicks "Delete home" and then "Cancel", when the dialog closes, then nothing is deleted.
- [ ] All tests pass. Reviewer approved. Verifier passed.
## Technical notes
Frontend rules for every M3 ticket (CLAUDE.md): reusable components; colors, type, spacing and sizes only from the design tokens in `frontend/src/styles/tokens.css`; light mode only; responsive at 390, 768 and 1280 px; touch targets at least 44 px; back buttons return to where the user came from. The frontend has no test runner (ask before adding one): checks are `npm run lint`, `npm run build` and the manual steps.
- `frontend/src/homes/MembersSection.tsx` (list, add by email, remove with confirm), `DeleteHomeSection.tsx`, shared `ConfirmDialog` component (focus trap, Esc closes, Cancel does nothing).
- Errors: `404` -> "No account with this email" under the field; `409` -> "Already a member".
- After delete: refresh the user's homes and go to the switcher (or "Create your first home" when none).
## Manual test steps
1. Settings of a home: add `sara@example.com` -> Sara appears in the list.
2. Add `nobody@example.com` -> "No account with this email" under the field.
3. Click "Remove" next to Sara, confirm -> she disappears.
4. Create a test home. "Delete home" then "Cancel" -> still there. "Delete home" then confirm -> gone; you land on the switcher (or "Create your first home").
5. Check at 390 px.
6. `cd frontend && npm run lint && npm run build`.
